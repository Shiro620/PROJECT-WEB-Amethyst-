# ♫ Amethyst Music — Музыкальный портал и плеер

Современный музыкальный веб-сервис со сквозным аудиоплеером, каталогом исполнителей и дискографий, а также личной библиотекой с автоматическим чтением тегов из MP3-файлов.

---

## ✨ Основные возможности

* **Сквозной мини-плеер внизу экрана:**
  * Управление воспроизведением (Play/Pause, следующий/предыдущий, случайный порядок, повтор).
  * Плавная интерактивная перемотка и регулятор громкости с быстрым Mute.
  * Синхронизация состояния через `localStorage` при переходе между страницами.
  * Управление с клавиатуры (горячие клавиши).
* **Каталог исполнителей:**
  * Карточки артистов (Lil Peep, GONE.Fludd, FRIENDLY THUG 52 NGG и др.).
  * Фильтрация по эпохам и жанрам, живой поиск.
  * Модальные окна альбомов с треклистами и возможностью прослушивания.
* **Личная библиотека («Моя музыка»):**
  * Загрузка отдельных треков и целых папок (Drag & Drop).
  * **Автоматическое извлечение ID3-тегов:** название, исполнитель, альбом, хронометраж и обложка извлекаются на лету.
  * Умный поиск по библиотеке.
  * Кнопка принудительного обновления метаданных файлов.
* **Дизайн:**
  * Адаптивная тёмная фиолетово-неоновая тема (Glassmorphism).
  * Оптимизировано для ПК и мобильных устройств.

## 🚀 Установка и запуск

### 1. Требования
* [Node.js](https://nodejs.org/) (версии LTS 18, 20 или новее)
* npm

### 2. Установка зависимостей
```bash
npm install
```

### 3. Наполнение базы данных
Создаёт файл `amethyst.db` и наполняет каталог артистами, альбомами и треклистами:
```bash
npm run seed
```

### 4. Запуск сервера
```bash
npm start
```

После запуска откройте в браузере:  
👉 **`http://localhost:3000`**

## ⌨️ Горячие клавиши

| Клавиша | Действие |
| :--- | :--- |
| `Пробел` | Воспроизведение / Пауза |
| `Стрелка влево` | Перемотка назад на 5 секунд |
| `Стрелка вправо` | Перемотка вперёд на 5 секунд |
| `Стрелка вверх` | Увеличить громкость на 5% |
| `Стрелка вниз` | Уменьшить громкость на 5% |
| `M` / `Ь` | Включить / выключить звук (Mute) |

## 🛠 Стек технологий

* **Backend:** Node.js, Express, SQLite3, Multer, `music-metadata`
* **Frontend:** HTML5, CSS3 (Flexbox, CSS Grid, Glassmorphism, CSS Transitions), Vanilla JavaScript
* **Database:** SQLite
